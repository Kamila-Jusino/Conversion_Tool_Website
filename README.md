Summary:
This project provides a centralized, easy-to-use website that enables users to convert between different units including **time, distance, temperature, number systems, currency, energy, and pressure**. It features a clean interface, responsive layout, and real-time currency updates using an API.

---
 Intended Audience

- General users needing quick conversions.
- Students in courses like physics and computer science.
- Anyone who works with international or scientific units.

---

 Key Features

1.  Number System Conversions : Binary ↔ Decimal ↔ Hex  
2.  Temperature Conversion : Celsius ↔ Fahrenheit  
3.  Distance Conversion : Inches, Feet, Yards, Miles  
4.  Time Conversion : Seconds, Minutes, Hours, Days, Months, Years  
5.  Currency Conversion : Real-time rates via API  
6.  Pressure Conversion : mmHg, Atmospheres, Torr, Pascals  
7.  Energy Conversion : Calories, Joules, Volts
8.  Responsive design to accommodate all devices (phones, tablets, desktops)
